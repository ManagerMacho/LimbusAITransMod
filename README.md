## 目录

```text
LimbusAITransMod
├── LATM_CN/     简体译文（加载这个）
```

## 使用

把 `LATM_CN` 导入你正在用的汉化加载方式（Hans 汉化包 / LimbusLocalize 语言目录等）。  
游戏热更后，旧译文可能错位或缺字，请拉本仓库最新 `LATM_CN`，不要长期用过期拷贝。
